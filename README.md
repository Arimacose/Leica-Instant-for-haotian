# Leica一瞬 for haotian

面向小米 15 Pro（haotian）的徕卡一瞬适配。当前正式发布 **R1-c** 与 **R2-c**。

| R1-c（Latest） | 优先 OEM 长焦输入，保留原包徕卡策略 
| R2-c | OEM 优先，按环境和输出组合隔离与回退 | 构建/静态验证通过；本版跨系统和录像效果尚未实测 

- 两包共用包名与数据，只能择一安装。
- 未修改官方相机、system 或 vendor。该相机可以与官方相机共存，不影响官方相机功能。
- 本相机移植自徕卡一瞬相机，添加了M9.M3.M10R三种徕卡滤镜及对应算法，保留了基础的AI相机功能，并在原包基础上加入了录像，适配了Dolby Vision
- 由于成片后需要在后台运算加入徕卡滤镜，成片后需等待数秒才能预览照片为正常现象
